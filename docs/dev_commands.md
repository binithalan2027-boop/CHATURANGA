# Dev Commands

From the root directory (`C:\Users\vinit\.gemini\antigravity\scratch\chaturanga`):

- **Install Dependencies:** `npm install`
- **Build All Packages:** `npm run build`
- **Run Tests:** `npm run test`
- **Lint:** `npm run lint`
- **Typecheck:** `npm run typecheck`
- **Start Development Servers (Client & Server):** `npm run dev`
